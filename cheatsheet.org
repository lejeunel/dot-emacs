* Vanilla Emacs cheatsheet

** Motion

~M-g g~ -- ~goto-line~ move cursor to given line
~M-g c~ -- ~goto-char~ move cursor to given character
~M-m~ -- ~back-to-identation~ jumps to first non-whitespace
~M-r~ -- ~move-to-window-line-top-bottom~ move cursor to top/center/bottom of window
~S-M-{f,b}~ select region while moving forward/backward
~M-{a-e}~ move backward/forward one sentence (depends on context/major-mode)

~C-M-{f,b}~ move forward/backward symbolic expression
~C-M-{a,e}~ move forward/backward function

~C-{number} <motion>~ applies motion ~number~ times, e.g.
    ~C-8 <up>~ moves 8 lines upwards

** Modify

~M-^~ -- ~delete-indentation~ removes all whitespace at point
~M-SPC~ -- ~just-one-space~ replace all whitespace at point with one space
~C-l~ -- ~recenter-top-bottom~
~M-%~ query replace
~M-0 C-k~ kill from cursor till beginning of line
~M-q~ -- ~fill-paragraph~ modifies the selected region to conform to maximum column width
~M-;~ -- ~comment-dwim~ comment or uncomment region
~M-(~ -- ~insert-parentheses~ enclose region whithin parentheses

~C-x C-x~ -- ~exchange-point-and-mark~ set mark to current point and select
from previous mark

** Indent

Select a region and type ~C-x C-i~. Next, use ~left/right~ or
~S-left/S-right~ to indent region.

** Explore sections/definitions of current buffer with ~imenu~

Open ~imenu~ with ~M-g i~ and scroll through the
detected paragraphs/sections/function of current buffer.

** Go to definition

- ~M-.~ (~xref-find-defitions~) jumps to the definition of
  item at point (class, function, variable, ...)
- ~M-,~ (~xref-go-back~) jumps back to location before invocation

** search, jump-to, and replace with ~consult-ripgrep~

Run ~consult-ripgrep~ to search the current project, or
a specified directory. View results in the mini-buffer.

This mini-buffer can be acted upon using ~embark-consult~.
Invoke ~embark-act~ with ~C-.~ and choose ~embark-export~ to
open the results in a separate grep buffer.

The buffer can be made editable with
~C-c C-p~ (~wgrep-change-to-wgrep-mode~).

Once changes have been made, ~C-x C-s~
applies changes to the files.

*** Specify custom path

Use the prefix key to specify the search path: ~C-u C-x p s~.

** Bookmark

Save a location in a file and assign it a name with
~C-x r m~. To jump to it do ~C-x r b~.

The bookmarks can also be accessed through the ~consult-buffer~
menu (~C-x b~).

** Insert text at multiple locations

To insert text on several lines at the same row, draw a zero-width
rectangle with ~C-x SPC~ and do ~C-x r t~ (~string-rectangle~).

** Repeating commands

~C-x z~ repeat last command, ignores input events, like moving around
~C-x (~ an ~C-x )~ start and end keyboard macro, respectively
~C-x e~ call last macro

** Killing / Copying / Yanking

~C-w~ kill (copy) selection
~M-w~ copy selection
~C-y~ yank (paste) selection
~M-y~ show kill-ring. Opens a fuzzy-search buffer to find copied/killed text

*** Word
~M-d~ kills from point until end of word (~kill-word~)
~C-<backspace>~~ kills from point until beginning of word (~backward-kill-word~)

*** Sentence
~M-k~ kills from point until end of sentence (~kill-sentence~)
~C-x- DEL~ kills from point until beginning of sentence (~backward-kill-sentence~)

*** Line
~C-k~ kills from point until end of line (~kill-line~)
~C-u 0 C-k~ kills from point until beginning of line
~C-S-<backspace>~ kills the whole line where point is placed (~kill-whole-line~)

*** Register

~C-x r s r~ copy region into register ~r~
~C-x r i r~ insert text in register ~r~

** Upcase/downcase

~C-x C-u~ make region upper-case
~C-x C-l~ make region lower-case

** Marking regions

- ~M-@~ marks from point till end of word
- ~M-h~ mark paragraph
- ~C-M-h~ mark /defun/ (or function in general)
- ~C-x h~ mark whole buffer
- ~C-M-u C-M-SPC~ select closest parentheses-like expression. Combines:
  - ~backward-up-list~ Place point at start of nearest parentheses-like expression)
  - ~mark-sexp~ (mark current following expression)
- ~C-SPC~ marks the start of a "linear region"
- ~C-x SPC~ marks the start of a rectangle
- ~C-x C-x~ swap the point (cursor) with the previous mark. Useful to expand the
  region "both ways".

  
** Jumping using marks

Hitting ~C-SPC~ sets a mark. This is useful when trying to
draw a region (e.g. by following with movements). Here, we
want to make a mark as a location in the buffer we know we
want to return to later on.

A first option is to set the mark (~C-SPC~), and straight after
do ~C-g~ to disactivate region selection.

A simpler approach is to disactivate the previous mark by
typing again ~C-SPC~ again. All together, that means
we do ~C-SPC~ twice in a row to push a mark in the mark-ring.
After navigating away from that mark, we return to it
using ~C-u C-SPC~.

- ~C-x c m~ runs ~consult-mark~ to preview marks

** Register storage

When working with several marks, we can mark a point
to a named register. To do so type ~C-x r SPC~ and enter
a letter in the mini-buffer. To jump to it, do ~C-x r j~.

** Jumping in compile/grep/rg modes

Certain modes produces outputs that correpond to lines
in files, e.g. compile-mode show errors to which we
can jump to with the ~<ENTER>~ key.

When launching a compilation, emacs will produce a new window
which will not be selected. This requires that we switch to ~C-x 0~,
select the error/line, and press ~<ENTER>~.

A simpler way is to type ~M-g M-n~ and ~M-g M-p~ to
move the point to the next and previous /error/, respectively.
here, /error/ means a line highlighted in the output buffer.

** Undo

Aside from regular undo called with ~C-/~, one may select a region and
the undo operations will only apply to that region.

** Registers

Registers are used to store text, numbers, positions, and more.
Use prefix ~C-x r~.

A preview buffer of all registers can be displayed with
~M-x view-register~.

*** String

Copy selected *string* with ~C-x r s~ and yank it with
~C-x r i~

*** Position (in a text buffer)

To save a position in a buffer and return to it later,
use ~C-x r SPC~ to push point position in register.
Next, use ~C-x r j~ to *jump* back to it.

*** Number

Initialize a number (integer) with value 0 using
~C-x r n~ and increment it with ~C-x r +~.

Set an initial value with universal argument: ~C-u 42 C-x r n~.
Increment by 5 with ~C-u 5 C-x r +~

This is useful when recording macros where each execution needs
to increment a number, i.e. we may record a macro that increment
a register.
